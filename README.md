# Бір сабақтың көрмесі — анимацияланған презентация

«Тіл кемістігі бар балаларды жалпы білім беру үдерісіне қосу» тақырыбындағы презентация. Ол «Экспозиция» шаблонымен (музей галереясы режимі) жасалды.

| Файл | Не |
|---|---|
| `index.html` | Презентацияның өзі: 11 слайд, бір кеңістіктегі Morph тәрізді қозғалыс |
| `preview.mp4` | Бүкіл маршрутты көрсететін қозғалыс жазбасы (1280×720) |
| `TEMPLATE.md` | Референстерді талдау, шаблон ережелері және ауысу кестесі |
| `assets/` | Суреттер |

**Ашу:** `index.html` файлын браузерде ашыңыз. Интернет болса, қаріптер Google Fonts-тан жүктеледі.

**Басқару:** → / Space — келесі · ← — алдыңғы · **N** — баяндамашы жазбалары · **F** — толық экран · **E** — мәтінді өңдеу · **Ctrl+S** — сақтау.
