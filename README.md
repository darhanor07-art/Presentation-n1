# Әр тұқымның өз көктеу уақыты бар

«Инклюзивті білім беру» пәнінің сессиялық жобасы. Жоба тіл кемістігі бар балаларды жалпы білім беру үдерісіне қалай қосамыз және қалай оқытамыз деген сұраққа жауап береді.

Презентация 30 слайдтан тұрады. Барлығы бір идеяға құрылған: бұршақтың төрт өсу кезеңі презентацияның төрт бөлімін береді. Басында қойылған сұраққа («Бала сөйлей алмаса, ол білім ала алмайды деген сөз бе?») 29-слайдта қайта ораламыз. Сол слайдта 1-слайдтағы тұқымнан гүл өсіп шығады.

| Файл | Не |
|---|---|
| `index.html` | Негізгі анимацияланған нұсқа. Суреттер файлдың ішіне кіріктірілген, сондықтан ол жалғыз өзі де ашылады |
| `presentation.pptx` | Morph ауысуы бар PowerPoint нұсқасы. Мәтіні өңделеді, баяндамашы жазбалары қосылған |
| `preview.mp4` | Бүкіл 30 слайдтың қозғалыс жазбасы |
| `TEMPLATE.md` | Instagram референстерін талдау және шаблон ережелері |
| `build/` | Құрастыру файлдары. Мазмұн — `content.py`, сахна — `scene.py`, объектілер — `props.py` |

## Бөлімдер

| Бөлім | Слайдтар | Мазмұны |
|---|---|---|
| I · Тұқым | 1–8 | Айарудың оқиғасы, басты сұрақ, сөйлеу бұзылыстарының түрлері, ротацизм мен ламбдацизм, Қазақстан деректері |
| II · Өскін | 9–13 | Дэвид Роуз (жеке слайд), UDL идеясы, UDL 3.0-тің үш қағидасы, Выготскийдің жақын даму аймағы |
| III · Жас өсімдік | 14–23 | Оқытудың жеті тәсілі (нұсқауды бөлу, көрнекі тірек, AAC, күту уақыты, дұрыс үлгі ұсыну, тұтығатын балаға көмек, жұптық кезек), бағалау, команда |
| IV · Гүл | 24–30 | Нәтиже, құндылықтар (Құрмет, Бірлік және ынтымақ, Әділдік және жауапкершілік), басқа пәнге көшіру, сұраққа жауап, авторлар |

## Ауысулардың мағынасы

- **Тұқымның жарылуы** — бөлімдер шекарасында (5, 9, 14, 24, 29). Сурет тұқым қабығы сияқты қисық сызықпен екіге жарылады да, камера жаңа кезеңге кіреді.
- **Портал-зум** — суреттің бір нүктесінен келесі көрініс ашылады.
- **Дыбыс толқыны** — сөйлеуге қатысты слайдтарда (7, 19).
- **Панорама** — бір бөлім ішіндегі қатар тәсілдер арасында.
- Экранның төменгі жағындағы сабақ 30 слайд бойы тұқымнан гүлге дейін өседі.

## Ашу және басқару

`index.html` → браузер. Пернелер: → / Space — келесі · ← — алдыңғы · **N** — баяндамашы жазбалары · **F** — толық экран · **E** — мәтінді өңдеу · **Ctrl+S** — сақтау.

`presentation.pptx` → PowerPoint 2019 / Microsoft 365 (Morph ауысуы осы нұсқаларда жұмыс істейді). Қаріптері — Cambria мен Calibri.

## Қайта құрастыру

```bash
python3 build/build_html.py                                   # index.html
python3 -m http.server 8765 &                                 # жергілікті сервер
node build/export_assets.js http://localhost:8765/index.html /tmp/export
python3 build/build_pptx.py /tmp/export                       # presentation.pptx
```
