# Саусақ ұшындағы жарық

**Емтихан тақырыбы №10:** Көзі нашар көретін балаларды жалпы білім беру үрдісіне қосу және бейімдеу, педагогикалық-психологиялық қолдау.
Презентация 30 слайдтан тұрады және берілген материалдың (23 слайд) бәрін қамтиды. Әр слайдта не тұратыны `SCENARIO.md` файлында жазылған.

| Файл | Не |
|---|---|
| `index.html` | Негізгі нұсқа: WebGL «видео» ауысулар мен anime.js анимациялары. Суреттер файлдың ішіне кіріктірілген |
| `presentation.pptx` | PowerPoint: әр слайдтың фоны — өздігінен ойнайтын ауысу видеосы. Мәтін өңделеді, HUD Morph арқылы ауысады |
| `presentation-morph.pptx` | Видеосыз, тек Morph. Телефондағы немесе бейнені автоматты ойнатпайтын PowerPoint-қа арналған |
| `preview.mp4` | HTML нұсқаның қозғалыс жазбасы |
| `SCENARIO.md` | 30 слайдтың сценарийі: мазмұны, визуалы, анимациясы, ауысуы, материалмен байланысы |
| `CREDITS.md` | Фотолардың авторлары мен лицензиялары |
| `build/` | Құрастыру: `content.py` (мәтін мен жазбалар), `gl.js` (шейдерлер), `deck.js` (anime.js сценарийлері) |

## Идея

Бүкіл презентация А.В. Бирилевтің ойынан басталады: *«Көзі көретін адам жарықты қолымен ұстай алмайтыны сияқты, соқыр адам жарықты елестете алмайды»*. Соңында ол жаңаша оқылады: *«Жарықты қолмен ұстай алмаймыз. Бірақ білімді балаға қолмен ұстатуға болады»*.

Құрылымы — Брайль ұяшығы: 6 нүкте = 6 бөлім × 5 слайд. Жоғарғы оң бұрыштағы ұяшықта әр бөлім басталғанда бір нүкте жанады. 29-слайдта алты нүкте түгел жанып, ⠙⠕⠎ («ДОС») сөзіне айналады.

## Ауысулар (WebGL шейдерлері)

| Ауысу | Мағынасы |
|---|---|
| iris | Көз қарашығы жабылып-ашылады — жаңа бөлім басталады |
| focus | Сурет «фокусқа түседі», көзілдірік кигендей |
| braille | Экран Брайль нүктелеріне бөлініп, нүкте-нүктемен ауысады |
| fog | Катарактадай тұман басып, кейін сейіледі |
| beam | Шам сәулесі экранды сызып өтеді |
| ripple | Дыбыс толқыны таралады |
| tunnel | Камера ішке қарай ұшып кіреді |

## anime.js 4.5 комбинациялары

- `scrambleText({chars:'braille'})` — мәтін Брайль таңбаларынан шешіледі;
- `splitText` + `stagger` — сөздер бұлыңғырдан фокусқа түседі;
- `svg.createDrawable` — сызбалар өздігінен сызылады;
- `spring` — серпінді карточкалар;
- уақыт шкаласындағы кілттік кадрлар (лупа, стилус, ата-ана карточкаларының FLIP ашылуы);
- `createTimer` — дыбыс толқыны;
- сандар есептегішпен өседі.

## Басқару

Пернелер: → / Space — келесі · ← — алдыңғы · **N** — баяндамашы жазбалары · **F** — толық экран.

Компьютер әлсіз болса, мекенжайға `?res=960` параметрін қосыңыз: ауысулар жеңілдейді.

## Шектеулер

- Canva-ның генерация лимиті бітіп қалды. Сондықтан фотолар Openverse пен Wikimedia Commons-тан алынған шынайы, ашық лицензиялы суреттер.
- motionsites.com — сатылымға қойылған бос домен, онда үлгілер жоқ.
- `presentation.pptx` ішіндегі бейненің автоматты ойнауы XML арқылы бапталған, бірақ нақты PowerPoint-та тексерілмеген. Бейне ойнамаса, `presentation-morph.pptx` нұсқасын қолданыңыз.
- 12-слайдтағы катаракта, торлы қабық және нерв атрофиясы — CSS сүзгісімен жасалған шартты симуляциялар. NEI-дің түпнұсқа симуляцияларын жүктеу мүмкін болмады.
