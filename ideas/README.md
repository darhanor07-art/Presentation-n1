# Идеялар банкі: презентация анимациясы

Келесі презентацияларға арналған дайын қор. Үш бөлімнен тұрады:

1. **Зерттеу.** YouTube пен Instagram-дағы ең көп қаралған және ең көп ұнаған презентация видеолары: 17 YouTube видео және 15 Instagram reel кадр-кадрымен қаралды.
2. **Комбо кітапханасы.** 28 комбо: бір слайдта бірнеше нысан бір мезетте бірнеше түрлі қозғалыспен жүреді. Комболар anime.js 4.5-пен жазылған, кез келген HTML презентацияға қосылады.
3. **Кітапханалар.** GitHub-тағы 45 анимация кітапханасының жұлдыз саны, лицензиясы және не үшін керегі.

| Файл | Не |
|---|---|
| [`combo-lab.html`](combo-lab.html) | **Комбо зертханасы**: 30 слайдтық тірі галерея. Әр слайдта бір комбо, слайдтар 12 түрлі ауысумен ауысады. Төменгі жолақта бір мезетте не қозғалатыны, anime.js функциялары және шабыт көзі жазылған. Файл интернетсіз ашылады |

| [`COMBOS.md`](COMBOS.md) | 28 комбоның толық сипаттамасы және әрқайсысын PowerPoint-те қалай жасау керегі |
| [`LIBRARIES.md`](LIBRARIES.md) | 45 кітапхана: санаттары, ★, лицензиясы, ескертпелер (GSAP, View Transitions, Manim) |

## Зертхананы басқару

| Перне | Әрекет |
|---|---|
| → · Space | Келесі комбо |
| ← | Алдыңғы |
| **R** | Комбоны басынан қайталау |
| **I** | Сипаттама жолағын жасыру/көрсету |
| **A** | Автоойнату |
| **F** | Толық экран |

Мекенжай параметрлері: `#12` — 12-слайдтан бастау; `?auto=1&dwell=6000` — әр слайдта 6 секундтан автоойнату.

## Комбоны өз презентацияңызға қосу

```html
<script src="anime.umd.min.js"></script>
<script src="ideas/lab/combos.js"></script>
<div id="slide" style="position:relative;width:1920px;height:1080px"></div>
<script>
  window.COMBO_IMG = {cls: 'img/cls.jpg'};
  const combo = Combos.spotlightCrop(document.getElementById('slide'));
  // слайдтан кеткенде: combo.destroy();
</script>
```

## Видео жазу

```bash
node ideas/tools/record.js "file://$PWD/ideas/combo-lab.html" out.mp4 --slides 30 --dwell 5600
```

Уақыт виртуалды, сондықтан компьютер баяу болса да видео 30 кадр/с біркелкі шығады.

## Қайта құрастыру

```bash
python3 ideas/build_lab.py     # combo-lab.html
python3 ideas/gen_docs.py      # RESEARCH.md, COMBOS.md, LIBRARIES.md
```

## Шектеулер

- **Instagram іздеуі.** Instagram-да «ең көп лайк» бойынша жалпы іздеу жоқ. Сондықтан reels Pinterest пен веб-іздеу арқылы табылды, ал лайк саны әр reel-дің өз бетінен алынды. Бұл — табылғандардың ішіндегі рейтинг, бүкіл Instagram бойынша емес.
- **Көрілмеген reel.** Бір reel (C2MnMPXPkFw, 1,75 млн ♥) тіркелусіз ашылмады: ол үшін тек лайк саны мен сипаттамасы бар.
- **Авторлық құқық.** Видео кадрлары репозиторийге салынбады. Комболар — тәсілдердің өз іске асыруымыз, суреттері — x ≠ 0 презентациясының 3D рендерлері.
- **Шартты деректер.** «Диаграмма + қайта тізу» комбосындағы сандар шартты мысал, ол слайдта жазылған.
