# 목판 · MOKPAN — «Қызыл айдың оюшысы»

Корей стиліндегі интерактив веб-манхваның (webtoon) пилоты, 1-бөлім. Оқырман бетті төмен айналдырған сайын сахналар кино сияқты ауысады, ал кей сахналарда оқырман әрекетке өзі қатысады.

**Референс.** Samana Studio-ның «The Nootturno Experience» сайты (Instagram Reel). Ол кадр-кадрмен талданды: [`ANIMATION_ANALYSIS.md`](ANIMATION_ANALYSIS.md). Біз одан тек стиль ДНҚ-сын алдық:
- гравюра сызығы;
- шектеулі палитра;
- scroll-кино;
- «ұстап тұру» интерактиві.

Ал тақырып (корей ағаш баспасы) мен барлық анимация жаңа, бірде-бірі референсті қайталамайды: [`DESIGN.md`](DESIGN.md).

## Идея

Жас оюшы қыз қызыл ай туған түні 81 259-шы ағаш тақтаны ояды. Тақтаға әріп емес, жолбарыс ойылады. Тақтаны бояп, қағазға басқанда жолбарыс тіріліп, қағаздан секіріп шығады.

Сурет стилі баспаның өзі. Әр өту баспа процесінің бір кезеңі: ою, бояу, басу, қағазды ажырату. Бүкіл сурет бір WebGL «баспа» шейдерінен өтеді: тон штрих сызығына айналады, ал қызыл бояу пластинасы сәл ығысып басылады.

## Басқару

- **Айналдыру:** тышқан дөңгелегі, тачпад немесе саусақ.
- **05 және 07 сахналар:** тышқанды басып тұру, экрандағы мөр-батырма немесе **Space**. Ұстамасаңыз, айналдырудың өзі әрекетті аяқтайды.
- Жүйеде `prefers-reduced-motion` қосулы болса, сілкініс, толқын және жарқыл өшеді.

## OpenMontage арқылы жасалғандар

[OpenMontage](https://github.com/OpenMontageInc/OpenMontage) жобаға `vendor/OpenMontage` submodule ретінде қосылған (скилл: `.claude/skills/openmontage`). Бәрі тек **тегін құралдармен** жасалды, API кілті қолданылған жоқ.

| Не | OpenMontage құралы | Нәтиже |
|---|---|---|
| 3D фондар | `threejs_world` → HyperFrames офлайн рендер | `assets/worlds/`: әлем спецификациялары. `assets/gen/`: `build/printize.py` арқылы тон мен түс карталарына айналған кадрлар. Олар 02 (жоталар), 07 (павильон, қола қоңырау, бөрене) және 09 (жоталар фоны) сахналарында қолданылады |
| Кейіпкерлер | `character_spec_generator → svg_rig_builder → pose_library_builder → action_timeline_compiler` | `assets/rig/generated/` — құралдардың өз шығысы. `assets/rig/` — біздің суретке бейімделген нұсқасы (оюшыда 28 бөлік, жолбарыста 13). Оларды `MK.rig` runtime жүргізеді |
| Қимыл | Ink Theater mocap каталогы | `assets/mocap/`: CMU walk және sit клиптері, оюшының сүйектеріне көшірілген |
| Видео | HyperFrames (ашылу/соңғы карталары) + ffmpeg | `trailer.mp4`. Саундтрек `build/sound/score.py`: каягым, жангу, қоңырау, фоли |

GLTF каталогтарына қол жетпегендіктен 3D әлемдер `blockout` деңгейінде жасалды. Түпкі көріністі баспа шейдері мен 2D сурет береді.

## Шектеулер

- WebGL2 қажет.
- Телефонда 3D кадрлар шамамен 100 МБ жад алады. Әлсіз құрылғыда кадр жиілігі төмендесе, сапа автоматты түрде 0.75-ке түседі.
- 3D таулардың шыңдары жұмсақ, себебі олар blockout деңгейінде.
- Бұл пилот, сондықтан сюжет мәтіндері әзірге уақытша.

## Қайта құрастыру

```bash
cd manhwa
python3 build/fonts.py                          # жаңа мәтін қосылса
python3 build/build_html.py                     # index.html
node build/record_preview.js --stills           # stills/, contact.jpg
node build/record_preview.js --video            # preview.mp4
node build/trailer/posters.js                   # posters/
bash build/trailer/make_trailer.sh              # саундтрек + trailer.mp4 (карталарды қайта рендерлеу: REBUILD_CARDS=1)

# OpenMontage (бір рет):
git submodule update --init --depth 1 ../vendor/OpenMontage
(cd ../vendor/OpenMontage && uv venv --python 3.11 .venv && . .venv/bin/activate && uv pip install -r requirements.txt)

# 3D фондарды қайта рендерлеу:
../vendor/OpenMontage/.venv/bin/python build/worlds/render_world.py ridges s02 s09
../vendor/OpenMontage/.venv/bin/python build/worlds/render_world.py pavilion
python3 build/printize.py ridges && python3 build/printize.py pavilion

# Кейіпкер rig-тері:
(cd ../vendor/OpenMontage && . .venv/bin/activate && python ../../manhwa/build/rigs/run_pipeline.py && python ../../manhwa/build/rigs/refine_rigs.py)
python3 build/rigs/bake_rigdata.py
```

## Дереккөздер мен лицензиялар

- **Шрифттер:** Song Myung, Black Han Sans, East Sea Dokdo, IBM Plex Mono, Cormorant Garamond. Барлығы SIL OFL 1.1 лицензиясымен (`fonts/OFL-*.txt`).
- **Mocap:** CMU Graphics Lab Motion Capture Database (тегін), OpenMontage Ink Theater арқылы алынды (`assets/mocap/ATTRIBUTION.md`).
- **OpenMontage:** AGPL-3.0. Ол тек құрал ретінде қолданылды. Оның коды бетке енбейді, бетке тек жасалған медиа кіреді. three.js (MIT) пен gsap тек офлайн рендер үшін қолданылды.
- **Референс видео:** Samana Studio. Тек талдау үшін қолданылды, видеоның өзі де, кадрлары да репозиторийге қосылмаған.
