# Стиль-референс: «The Nootturno Experience» → манхва

**Дереккөз:** Instagram Reel, Samana Studio (Immersive Web Design), https://www.instagram.com/reel/DfFzpXTR9AY/.
Ұзақтығы 23.5 с, 1080×1920, 60 fps. Видеода ноутбук экранына түсірілген интерактивті веб-сайт көрсетіледі. Сайт тачпадпен айналдырылады (scroll).
Кадрлар 2 fps жиілікпен (47 кадр) және 16 негізгі сәт жоғары ажыратымдылықпен талданды.

> Видео мен кадрлар авторлық құқықпен қорғалғандықтан репозиторийге қосылмады. Қайта жүктеу үшін:

## 2. Визуал тіл (design tokens)

### Палитра: 3 негізгі + 1 акцент
Экраннан камерамен түсірілгендіктен, мәндер түзетілген шамамен алынған.

| Рөл | Түс | Қолданылуы |
|---|---|---|
| **Қызыл (негізгі фон)** | `#D9140B` (≈ #C8170D…#E3200F) | Аспан, қабырға, еден, сұйықтық |
| **Сия қара** | `#0B0B0A` | Контурлар, штрихтар, силуэттер |
| **Қағаз ақ** | `#EFECE3` (жылы, таза ақ емес) | Панельдер, колонналар, мәтін блоктары |
| **Охра-сары (кейіпкер)** | `#E2C02A` | Тек басты кейіпкердің киімі және «сиқыр» бөлшектері |
| Акцент (сирек) | көк `#2E9BD6`, жасыл `#46B85A` | Тек таңдау сәтінде (бөтелкелер) |

**Ереже:** кадрда ең көбі 3 түс болады (қызыл, қара, ақ). Сары тек кейіпкерге/маңызды затқа беріледі, сондықтан көз бірден соған түседі.

### Сурет техникасы
- **Гравюра / woodcut штрихтау:** көлеңке реңкпен емес, параллель сызықтармен беріледі (тік, толқынды, кросс-штрих). Колонналар мен киім тік жіңішке сызықтардан тұрады.
- **Қатты сия контуры**, градиент жоқ. Жұмсақ көлеңке орнына flat fill + штрих қолданылады.
- **Силуэт:** кейіпкер көбіне қара силуэт немесе арқасынан көрінеді. Бет тек көздердің жақын планында ашылады, бұл жұмбақ әсерін береді.
- **Текстура:** ағаш талшығы, мәрмәр жарықшағы, қағаз дәні. Бәрі сызықпен беріледі.

### Типографика
- **Логотип:** жоғары контрастты display serif (Didone/Bodoni типті), әріптер қосылған лигатуралар («OO», «TT»), «C» жарықшақтанған. Ұқсас тегін шрифттер: *Playfair Display SC*, *Bodoni Moda*, *Abril Fatface*.
- **Капшондар (баяндаушы мәтін):** кішкене UPPERCASE sans/mono, ақ тікбұрышты блокта, жұқа қара жиек. Ұқсас: *Space Grotesk*, *IBM Plex Mono*.
- **UI:** оң жақ жоғарғы бұрышта «EXPERIENCE» батырмасы, ақ pill-дөңгелек батырмалар («HOLD & POUR», «CHOOSE FLAVOR»).

### Композиция және қозғалыс
- **Scroll = уақыт:** әр scroll қадамы бір «панель». Сахналар бір-біріне жалғасып кетеді, бөлек слайд сияқты көрінбейді.
- **Өтулер:** вертикаль wipe, сия ағысы (штрих-glitch), шеңбер ішіне zoom, панель-стек, жылдамдық сызықтары.
- **Кино-ракурстар:** extreme close-up (көздер, қол) → wide (зал) → over-the-shoulder → action. Манхвадағыдай ырғақ.
- **Inset-панельдер:** негізгі сахнаның үстінде кішкене рамкадағы реакция кадры.
- **Интерактив:** «ұстап тұр» (hold) батырмасы анимацияны алға жылжытады. Оқырман сахнаға өзі қатысады.

## 3. Корей манхвасына (webtoon) бейімдеу нұсқаулығы

Сайттың құрылымы тік webtoon форматына өте жақын: екеуі де тік scroll, панельдер арасында ырғақ, бір экранда бір әсер.

### Формат
- Ені **800 px** (Webtoon стандарты), биіктігі еркін. Бір эпизод 40–60 панель.
- Әр панель **бір негізгі әрекет** көрсетеді. Арасындағы бос қызыл/ақ/қара кеңістік уақыттың өтуін білдіреді (сайттағы scroll паузалары сияқты).

### Стиль ережелері (чек-лист)
1. Фон тек **қызыл / ақ / қара**. Сары тек басты кейіпкерге беріледі.
2. Көлеңке **штрихпен** беріледі (гравюра), airbrush/градиент қолданылмайды.
3. Кейіпкердің беті сирек көрсетіледі. Эмоция **көздердің extreme close-up** кадрларымен беріледі (көлденең ақ жолақ-панель).
4. Баяндау ақ тікбұрышты **капшон-блоктарда** жазылады (UPPERCASE, кішкене). Диалог үшін ақ көпіршік, қара жиек қолданылады.
5. SFX (дыбыс сөздері) корейше стильде қатты сиямен, қисайтып жазылады: 쾅 (гүрс), 쨍 (шыңғ), 휘익 (ысқырық). Аудармасы кішкене жазылады.
6. Экшн сахналарда **радиал speed lines**, ақ «жарылыс» фон және ұшқан бөлшектер болады.
7. Тарау соңында **титул-панель**: display serif, жарықшақтанған әріп, тас сынықтары.

### Сайттан алынған панель үлгілері (манхва баламасы)
| Сайттағы сахна | Манхва панелі |
|---|---|
| Қол батырманы ұстайды | Ашылу: қолдың extreme close-up кадры, капшон «Ол қолын созды…» |
| Сұйықтық төгіледі | Толық ені бар «сплэш» панель, қызыл сұйықтық келесі панельге ағып өтеді |
| Қызыл шеңбер + силуэт | Ұзын тік панель: ортада қызыл ай, кейіпкер арқасынан |
| Сия ағысы | Панельдер арасындағы өту: ақтан қараға тік штрихтар (gutter-ді толтырады) |
| Көздер жолағы | Көлденең жіңішке панель, тек көздер |
| Таңдау (3 бөтелке) | Үш тең панель қатар, әрқайсысы өз түсімен |
| Ұшу | Қос биіктіктегі экшн-панель, speed lines |
| Бағаналар қирайды | Қисайған (diagonal) панель шекаралары, сынықтар рамкадан шығып тұрады |
| Логотип | Тарау атауы бар титул-бет |

### Келесі қадамдар
1. Сюжет пен кейіпкерді таңдау (сіздің идеяңыз).
2. 1-эпизодқа сценарий және панельдер раскадровкасы.
3. Панельдерді жасау. Екі жол бар:
   - HTML/SVG + штрих-шейдерлер арқылы интерактив webtoon (сайттағыдай scroll-анимациямен);
   - статикалық PNG панельдер.
4. Капшон, SFX және логотипті қосу, тік эпизодты құрастыру.
