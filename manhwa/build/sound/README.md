# MOKPAN дыбыс жолы (score.py)
Барлығы түпнұсқа, синтезделген (numpy), тұрақты seed — API кілті де, сыртқы сэмпл де жоқ.
Іске қосу: `python3 build/sound/score.py` (алдымен `node build/trailer/timeline.js`) → `assets/audio/score.wav` (48 кГц стерео, ұзақтығы timeline-ға тең), `score.m4a`, `sting_open/end.wav`.
- Гаяgeum: Karplus–Strong шегі + сәл бұралған екінші шек, ұзақ ноталарда 농현 вибрато, 평조 гаммасы (D E G A B); фразалар сахналармен тыныс алады.
- Дроне (daegeum педалі): D2 синус + сүзілген шу тынысы, s02-ден s03 соңына дейін.
- Janggu: терең «кун» және өткір «деок» — мөр соққысы, тырнақ ізі (t06), жарықшақ (s08), жолбарыс ақырысы.
- Ағаш «так»: s01 және s09 мөрлері; s05 қағаз түскенде/сыпырғанда — қағаз желпінісі (AM шу), ысқылау.
- Қылқалам swish: s04 (p 0.55, 0.72), s08 лентасы; qашау сызбасы: s01/s04.
- s07: ұстап тұру кезінде көтерілетін дрон, жіп босағанда +0.28 с-тан кейін ғибадатхана қоңырауы (110 Гц, 1/2.76/5.4/8.9 бөліктері, 6–9 с шашырау, соғу) — қалған дыбыс 0.78-ге басылады (ducking).
- Финал: s09 мөрінен кейін ұзақ D ноталары, жұмсақ fade-out.
- Мастеринг: тanh жұмсақ шектеуіш, шамамен −16 LUFS, пик ≤ −1 dBFS. Cue уақыттары — `build/trailer/timeline.json` (events).
