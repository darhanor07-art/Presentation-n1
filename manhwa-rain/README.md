# Тоқтамайтын жаңбыр — интерактив веб-манхва (scroll)

## Идея
Тік scroll манхва, 10 бет ([`SCENARIO.md`](SCENARIO.md)): «Бұл қалада жаңбыр біреуді бүкіл қала ұмытқанда басталады». Төмен айналдырған сайын қабаттар параллаксмен жылжиды, жаңбыр (3 тереңдік, шашырау, шам конусы, Санжардың айналасындағы құрғақ шеңбер, 8-бетте кері жауу), шалшықтағы толқындар және әйнектегі сынатын тамшылар scroll мен уақытқа байланған. Барлық фон, кейіпкер және көз **p5.brush** арқылы салынған (`paint/`), Blender де, фото да жоқ. Палитра: түн `#141B26`, шифер `#26313F`, болат `#3D4C5E`, жаңбыр көгі `#6E89A3`, тұман `#C5D0DA`, қағаз `#EEF1F2`, жалғыз жылы акцент — сары `#F2C230`.

## Файлдар

## Көз ережесі
Көз терезесі тек үш рет: 2-бетте Мерейдің көзі (жабық -> жартылай -> ашық), 6-бетте Санжардың көзі, 9-бетте екі көз жолағы. Қалған кірістірмелер (3: қолшатыр жиегі, иық, сары жең; 4: шалшық; 5: скотч, ағып бара жатқан сия, әріпке тамшы; 6: бағдаршам, фара жарқылы) көзсіз; олар ақ жарқылмен ашылып, фоннан 1.6–1.7 есе жылдам өтеді.

## Өтулер (9 бөлек градиент, `TR` ішінде)
| Өту | Функция | Градиент |
|---|---|---|
| 1 -> 2 | `streak` | қиғаш жаңбыр сызықтары кезекпен құлайды: шифер -> жаңбыр көгі |
| 2 -> 3 | `fogwipe` | буланған әйнекті алақан доғамен сүрту: тұман -> мөлдір радиал |
| 3 -> 4 | `umbrella` | 8 сегментті қолшатыр айналып ашылады: түн -> болат |
| 4 -> 5 | `ripple` | бір нүктеден концентрлі шеңберлер: жаңбыр көгі -> тұман |
| 5 -> 6 | `bleed` | акварель сиясы жоғарыдан төмен жайылады, түйіршікті жиек: болат -> шифер |
| 6 -> 7 | `headlight` | фара жарығы көлденең сыпырады: ақ -> сары -> мөлдір |
| 7 -> 8 | `drip` | бояу тамшылары ағатын перде: түн -> болат |
| 8 -> 9 | `rise` | жаңбыр сызықтары төменнен жоғары: тұман -> жаңбыр көгі |
| 9 -> 10 | `flash` | найзағай: ақ -> суық көк, тарамдалған сызық |

## Мәтін анимациялары (JS, `t` пен прогрестен; CSS keyframes жоқ)
Капшон: сөзбе-сөз (blur -> анық). 1-беттегі соңғы жол мен 10-беттегі үлкен жол: әріптер бір-бірден жарқ етеді. Атау: солдан оңға маска. Көпіршік/ой: серіппелі масштаб, жолма-жол (4-беттегі «…ал мен жоқпын.» дірілдейді). Дауыс (9): төртбұрыш, тік жиегі үзік-үзік, шағын діріл. Шок («Мерей!»): секіріп шығады, дірілдейді. SFX: жұқа курсив, әріптер дірілдейді. «Жалғасы бар…»: қолмен жазғандай солдан оңға.

## Басқару
Scroll / touch / дөңгелек. `file://` жұмыс істейді. Детерминді режим: `index.html?capture=1`, содан кейін `await window.__ms.render(sVH, tSec)`; қате болса `document.body.dataset.err`, жүктеу біткенде `#loader.done`; `window.__ms.placeholders` әлі салынбаған кілттерді көрсетеді.

## Қайта құрастыру
```
node build/paint.js                 # p5.brush ассеттерін салу (немесе: node build/paint.js hook_ poster_03 --quick)
python3 build/build_html.py         # index.html
PW_PATH=/opt/node-tools/node_modules/playwright node build/record.js --stills   # немесе --video
```
