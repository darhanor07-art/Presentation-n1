# Көктемнің соңғы гүлі — интерактив веб-манхва (scroll)

## Идея
Тік scroll манхва: оқырман төмен айналдырған сайын 10 бет ауысады ([`SCENARIO.md`](SCENARIO.md)). Механика Nootturno сайтынан алынған ([`../manhwa/ANIMATION_ANALYSIS.md`](../manhwa/ANIMATION_ANALYSIS.md)): scroll-ға байланған қабаттар, параллакс, фоннан 1.6–2 есе жылдам өтетін «көз терезелері», капшондар мен көпіршіктердің өз параллаксы, жұмсақ scroll. Стилі гравюра емес, живопись: индиго/лаванда/периванкль градингі, bloom, виньетка, түйір, ай нұры, жапырақшалар мен тұман.
Әр өту сценарийге сай және бөлек градиентті (төменде кесте).

## Файлдар
| Файл | Не істейді |
|---|---|
| `index.html` | дайын, бір файлды нұсқа (шрифт, JS, WebP base64) |
| `src/engine.js` | Canvas2D компоновщик, ассет іздеу, терезелер, жапырақшалар, тұман, 9 градиент өту, post, DOM мәтін анимациялары |
| `src/scenes.js` | 10 бет: камера, қабаттар, терезелер, мәтіндер |
| `src/placeholders.js` | ассет жоқ болса, көз бен кейіпкердің салынған орынбасарлары |
| `build/build_html.py` | `assets/manifest.json` + `blender/moonlit-castle/renders` -> `index.html` |
| `build/record.js` | Playwright: `--stills` (`stills/`), `--video` (`preview.mp4`, 720×1280, 30 fps) |
| `stills/`, `preview.mp4` | тексеру кадрлары мен превью |

## 10 бет
| # | Бет | Кадр | Ұзындық (VH) |
|---|---|---|---|
| 1 | `moon` хук | `plate_moon` / `moon_sky`+`moon_castle` параллакс | 4.2 |
| 2 | `macro` ояну | `plate_macro`, фокус бұлдырдан анық | 3.4 |
| 3 | `feet` аяқ басу | `feet_00..11` кадр тізбегі, scroll-мен 2 толық қадам (қысылған индекс + кросс-фейд) | 4.2 |
| 4 | `ots_castle` иық артынан | `plate_ots_castle` | 3.6 |
| 5 | `gate` қақпа | `plate_gate`, терезелер scroll-мен жанады, Айару силуэті | 3.6 |
| 6 | `tower` мұнара | `plate_tower` | 3.4 |
| 7 | `ots_tair` кездесу | `plate_ots_tair` | 4.0 |
| 8 | `hall` сарайдың іші | `hall_back` (баяу) + `hall_fg` (жылдам) параллакс, камера алға жүреді | 4.2 |
| 9 | `pair` екі көз | `aiaru_pair_0..3`, қарашықтар scroll-мен тарылады | 3.6 |
| 10 | `wide` финал | `plate_wide` (орынбасар `wide`), жапырақша құйыны | 4.2 |

Плейт жоқ болса: ұқсас плейт (`alt`) немесе бар орынбасар суреті палитра градиентімен және «placeholder · аты» жазуымен салынады; `window.__ms.placeholders` тізімі нені әлі рендерлеу керектігін көрсетеді.

## Көз ережесі
Әр көз бір рет қана: 2-бетте Айарудың көзі (жабық -> жартылай -> ашық), 6-бетте Тайрдың көзі (тар, ұзын терезе), 9-бетте екі көз жолағы (бүкіл бөлімде бір рет, беттің басты кадры). Қалған кішкене «терезе» кірістірмелері (бір-екі кадр ақ жарқылмен ашылады, фоннан 1.6–1.7 есе жылдам өтеді) көзсіз: 3-бетте басылған аяқ (басқа фаза, ірі план), 4-бетте лента, 5-бетте қақпа мен жанған терезе, 8-бетте шам жалыны, 10-бетте жапырақшалар.

## Өтулер (9 бөлек градиент)
| Өту | Функция (`engine.js`, `TR`) | Градиент |
|---|---|---|
| 1 -> 2 | `moonburst` | радиал: ай ақшылы -> лаванда -> мөлдір, сәулелі жарылыс |
| 2 -> 3 | `diag` | сызықтық 135°: индиго -> периванкль, жұмсақ жиекті диагональ жуу |
| 3 -> 4 | `blinds` | 7 тік жолақ, лаванда -> кәріптас, кезекпен (stagger) |
| 4 -> 5 | `conic` | конустық: индиго / күлгін / лаванда, қақпа ортасынан сағат тілімен |
| 5 -> 6 | `slideup` | кадр жоғары жылжиды, жиегінде кәріптас -> индиго жылы сызық |
| 6 -> 7 | `iris` | радиал-ирис: периванкль -> түн, қарашық сияқты жабылып-ашылады |
| 7 -> 8 | `meshmist` | mesh: қозғалатын лаванда/периванкль дақтары, тұман сияқты ериді |
| 8 -> 9 | `doors` | екі есік қанаты: түн градиенті, кәріптас ішкі жиек, екі жаққа ашылады |
| 9 -> 10 | `bloom` | сызықтық 180°: ақ -> лаванда жарқыл |

## Мәтін анимациялары (барлығы JS-пен, `t` пен прогрестен; CSS keyframes жоқ)
| Мәтін | Анимация |
|---|---|
| Капшон (`cap`) | сөзбе-сөз stagger: blur 6px -> 0, төменнен 12px көтеріледі, opacity |
| Хук жолы 3, соңғы «ал егер» | әріптер бір-бірден жарқ етеді (ақ glow), үлкен шрифт |
| Атау | `mask-image` арқылы солдан оңға ашылады |
| Көпіршік / ой (`bub`, `thought`) | серіппелі масштаб (~1.08 асып, тұрақтанады), мәтін жолма-жол шығады |
| Жоғарыдан дауыс (5-бет) | `voice`: тік-сызықты жиегі бар төртбұрышты көпіршік, құйрықсыз, шағын діріл |
| SFX | жұқа курсив, әріптер синус бойынша кішкене дірілдейді |
| «Жалғасы бар…» | қолмен жазғандай солдан оңға ашылады, қалам ұшында жарық нүкте |
Мәтін `mkItem` ішінде бір рет span-дарға бөлінеді, стильдер `updItems` ішінде әр кадрда есептеледі.

## Басқару
Scroll / touch / тышқан дөңгелегі. Құрастырылған бетті ашу жеткілікті (`file://` жұмыс істейді). Детерминді режим: `index.html?capture=1`, содан кейін `window.__ms.render(sVH, tSec)`; қате болса `document.body.dataset.err`, жүктеу біткенде `#loader.done`.

## Қайта құрастыру
```
python3 build/build_html.py                 # ассеттерді қайта оқып, index.html жазады
PW_PATH=/path/to/playwright node build/record.js --stills   # немесе --video
```
Ассеттер аты бойынша манифесттен ізделеді (`plate` атында `moon|macro|gate|tower|garden|ots_castle|ots_tair|hall`; `layer` атында сахна id + `sky|moon|towers|mist|bg|mid|wall|tower|flowers|castle`; `char` атында `aiaru`/`tair`; `eye`: `aiaru_closed/half/open`, `tair_open` (немесе `tair_narrow`), `aiaru_pair_0..3` (1600×560 екі көз жолағы); `seq` (кадрлар тізбегі): `feet_00..11`; жаңа плейттер `plate_ots_castle`, `plate_ots_tair`, `plate_hall`, қабаттар `hall_back`, `hall_fg`). Табылмағаны автоматты түрде орынбасарға түседі, сондықтан рендер келгеннен кейін кодты өзгертпей `build_html.py` жіберу жеткілікті.
