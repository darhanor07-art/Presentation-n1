# Ай нұрындағы сарай · Blender (bpy) + Cycles

## Идея

Манхва парағының жоғарғы оң жақ панелі (түнгі аспан, үлкен толған ай, үстінде үшкір шатырлы мұнаралары бар готикалық сарай, ал алдыңғы жоспарда бозғылт көгілдір-күлгін гүлдер алқабы) нағыз 3D орта ретінде қайта құрастырылды. Түс палитрасы суреттегідей: индиго, күлгін және периванкль-көк түстер, ал жалғыз жылы акцент ретінде терезелердегі кәріптас сары жарық қалды.

Барлығы Blender-дің `bpy` Python модулімен (5.3) нөлден, процедуралық түрде құрылады. Сыртқы модель немесе текстура жоқ, кездейсоқ сандар бекітілген (seed).

Сахнаның құрамы (нақты масштаб, метр):

- **Жер бедері.** Fbm-төбешіктер, камерадан ~330 м қашықтықтағы сарай төбесі, камераға қарай еңкейетін алқап, алыстағы таулар және ағаш көлеңкелері.
- **Шөп.** ~170 000 қисық жапырақ шоғыры, камераға жақын жерде тығыздау.
- **Гүл.** Бес жапырақшалы, қалыңдығы бар, сәл ойыс гүл. Ортасы ақшыл, шеті периванкль-көк, жарықты өткізетін (translucency/subsurface), аналықтары, сабағы мен жапырақтары бар. 3 нұсқа, ~75 000 дана (кездейсоқ масштаб, бұрылыс, көлбеу), линзаға жақын 7 «қаһарман» гүл (бокэ).
- **Сарай.** Орталық октагональ донжон, 12 жіңішке мұнара, бұрыштық мұнарашалар, зубцылар, қабырғалар, контрфорстар, үшкір аркалы терезелер (жылы жарық түсетіні де, қараңғысы да бар), тас пен шифер материалдары, шатыр ұштарында финиалдар.
- **Аспан мен ай.** Индиго → күлгін градиент, процедуралық жұлдыздар, сүттей тұман, кратерлі ай (аймен бағытталған күн лампасы).
- **Атмосфера.** Көлемді тұман: жалпы дымқыл, сарай етегіндегі аңғар тұманы, жердегі жұқа тұман. Ауада ~260 гүл жапырақшасы қалқып тұр.
- **Камералар.** `CAM_HERO` (1080×1350, 35 мм, DOF), `CAM_WIDE` (24 мм), `CAM_FLY` (6 с, 24 fps, алға және жоғары ақырын жылжу).
- **Компоситор.** Fog Glow (айдың гало эффектісі, терезелердегі жарқыл), AgX көрініс түрлендіруі.

## Файлдар

| Файл | Не |
|---|---|
| `build_scene.py` | Бүкіл сахнаны құрады және `moonlit_castle.blend` файлына сақтайды |
| `render.py` | `hero.png`, `wide.png`, `clay.png`, `flyby.mp4` рендерлейді |
| `moonlit_castle.blend` | Дайын сахна (~12 МБ) |
| `renders/hero.png` | Негізгі кадр 1080×1350 |
| `renders/wide.png` | Кең кадр 1600×900 |
| `renders/clay.png` | Ақ саз (clay) нұсқа, модельдеу сапасын көрсетеді |
| `renders/flyby.mp4` | Гүлдер үстімен ұшу, 540×675, 24 fps |
| `renders/iterations/` | Сапа циклінің аралық кішкентай JPG-лері |
| `renders/_frames/` | Видео кадрлары (git-ке кірмейді) |

## Қайта құрастыру

```bash
# 1) bpy орнату (Python 3.13)
/usr/local/bin/python3.13 -m venv /root/.venvs/bpy
/root/.venvs/bpy/bin/pip install bpy==5.3.0

# 2) сахнаны құру (~2 секунд)
cd blender/moonlit-castle
/root/.venvs/bpy/bin/python -W ignore build_scene.py

# 3) рендер (CPU, 4 ядро)
/root/.venvs/bpy/bin/python -W ignore render.py hero      # ~20 мин
/root/.venvs/bpy/bin/python -W ignore render.py wide
/root/.venvs/bpy/bin/python -W ignore render.py clay
/root/.venvs/bpy/bin/python -W ignore render.py flyby     # кадрлар renders/_frames/, ffmpeg кодтайды
/root/.venvs/bpy/bin/python -W ignore render.py hero --quick   # жылдам алдын ала көру (24 сэмпл)
```

Видео рендері үзілсе, команданы қайта іске қосу жеткілікті: дайын кадрлар өткізіліп жіберіледі.

## Шектеулер

- GPU жоқ, рендер Cycles CPU-да. Сондықтан сэмпл саны шектеулі, кескін OpenImageDenoise арқылы тазартылады.
- Мұнаралардың тас өрімі hero кадрда әрең көрінеді (сарай 330 м қашықта). Микро-дисплейсмент орнына bump қолданылған.
- Ағаштар жеңілдетілген (блоб және конус), алыстағы гүлдер жеке-жеке емес, жер шейдеріндегі дақ ретінде берілген.
- Жапырақшалар бейнеде тек бір бағытқа бірқалыпты жылжиды, жеке желмен тербелмейді.
- Видео төмен ажыратымдылықта (540×675) және аз сэмплмен рендерленді, ал көлемді тұман (жердегі жұқа қабат) видеода өшірілген.
- Сурет референс панельдің көңіл-күйін қайталайды, бірақ кейіпкерлер мен нақты сарай дизайны көшірілмеген.
