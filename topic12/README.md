# x ≠ 0

**Тақырып №12 · математикалық редакция.** Тіл кемістігі бар балаларды жалпы білім беру үдерісіне қосу: математика сабағындағы шешім.
**Авторлар:** Утепберген Айсамал, Еділ Ақерке, Тұрлан Қарақат — математика пәнінің мұғалімдері.

| Файл | Не |
|---|---|

## Идея

Сөйлемейтін баланың білімін **x** деп белгілейміз. Сабақта бала ештеңе айтпаса, журналда x нөлге тең болып қалады.

- **Ілмек-сұрақ (7-слайд):** *Сөйлемейтін баланың білімі нөлге тең бе?* — экранда «x = 0 ?».
- **Жауап (29-слайд):** *Жоқ. Айарудың x-і — 12.* — «x ≠ 0».

Баяндама есеп шығару тәртібімен құрылған: Шарт → Белгісіз → Формула → Шешу → Тексеру → Жауап. Бөлімнің аты жоғарғы сол жақта тұрады. Слайд нөмірі мен саны слайдтың ішінде жазылмайды.

## Бір сынып — көп ракурс

Камера мектептің сыртында таң атқанда басталады. Сосын ашық терезе арқылы ұшып сыныпқа кіреді. Ішінде мына ракурстардан көрсетеді:

- тақта мен мұғалім;
- Айарудың және оның жұбы Ерасылдың жақын планы;
- партаның үсті және парта асты;
- терезеден аулаға қарау: балалар асфальтқа салынған сандармен «классика» ойнап жүр;
- қабырғадағы плакаттар, Роуздың портреті, сағат, сан түзуі, мұғалімнің үстелі.

Соңында камера түнгі мектептен шегінеді: тек біздің сыныпта жарық жанып тұр, ал титрлар төменнен жоғары көтеріледі.

## Ауысулар (20 түр, әрқайсысы ең көбі 2 рет)

| Камера жолымен | Кадрдың өзімен |
|---|---|
| Таң · терезеден ұшып кіру · қамшы-панорама · фокусты аудару · вертиго-кран · парта астына сүңгу · терезеге шығу · терезеден ұшып шығу · кран артқа | Дыбыс толқыны · бөлінген экран · бор шаңы · сан түзуі · дәптер парағы · циркуль · теңдік белгісі · бөлшек · ондық рамка · сағат тілі · көбейту белгісі |

Камера жолымен ауысулар үшін 3D сахнада камера бір ракурстан екіншісіне үздіксіз ұшады. Кадрмен ауысуларда алдыңғы кадр «қатады», ал жаңасы шейдер арқылы ашылады.

## Слайдтан слайдқа көшетін детальдар

| Деталь | Жолы |
|---|---|
| **x** | Мұқабадағы тақырып → «x = 0 ?» → парта астындағы карточканың жанында → дәптердің бұрышында → «x-і табылды» → құндылықтар → «x ≠ 0» → титрлар |
| **=** | Мұқабадағы «≠» → «7 + 5 = ?» → «x = 0 ?» → UDL → құндылықтар → қайтадан «≠» |
| **«12» карточкасы** | Айарудың қолында → партада → парта астында → сан түзуіндегі 12-ге қонады → жұптық жұмыс → төрт жолдың бірі → партаның ортасында |
| **Сан түзуі 0–20** | Экранның астына түседі → тіректер тізімінде → жұптың партасында → төрт жолдың бірі |
| **Шеңбер, үшбұрыш, шаршы** | Үш автор. Олар мұқабада қолтаңба болады, сосын шешу жоспары, UDL, құндылықтар арқылы өтіп, титрларда есімдердің жанында көтеріледі |

## Дизайн

- **«Бор» палитрасы (мәтін):** сия `#12161F`, бор `#F5F0E6`, бор-сары `#F4C95D`, бор-маржан `#F28B6C`, бор-жалбыз `#8FD3B6`.
- **«Сынып» палитрасы (3D):** тақта `#26443A`, бал-ағаш `#C8925A`, сылақ `#EFE4CF`, кірпіш `#B9573A`, аспан `#9CCBEA`.
- **Қаріптер:** Rubik (мәтін) және Caveat (бормен жазылғандай қолжазба).
- **Кескін:** жұмсақ көлеңке, терезеден түсетін күн сәулесі, тереңдік бұлыңғырлығы (DOF), түс градациясы, үлбіршек (grain). Жарық таңертеңнен түнге дейін өзгереді.

## Шектеулер

- **Компьютер:** HTML нұсқаға WebGL2 және жақсы видеокарта керек. Әлсіз ноутбукта `?q=lo` қолданыңыз немесе PPTX нұсқасын ашыңыз.
- **Бейненің автоматты ойнауы:** `presentation.pptx` ішінде бұл XML арқылы бапталған, бірақ нақты PowerPoint-та тексерілмеген. Бейне ойнамаса, `presentation-morph.pptx` қолданыңыз.
- **Қаріптер:** PPTX ішінде Rubik мен Caveat көрсетілген. Олар орнатылмаса, PowerPoint басқа қаріп қояды да, жолдар сәл жылжиды. Қаріптер `fonts/` папкасында.
- **Кейіпкерлер мен деректер:** Айару мен Ерасыл — ойдан құрастырылған кейіпкерлер. 26-слайдтағы бақылау жазбасы да ойдан құрастырылған мысал.
